# 정보 지도 — "투자에 영향을 주는 정보"의 전 범주와 커버리지

> 2026-08-20 · 질문: **기획의 데이터가 투자 정보의 전부인가?** → 아니었다. 원래 기획은 사실 계층(공시·시세·뉴스·한국 거시)만 커버했고 4개 범주가 비어 있었다. 리서치 3건(수급 / 기대치·일정 / 거시·산업)으로 각 범주의 무료·개인 경로를 확정했다. 소스 대부분은 조사 에이전트가 실제 호출로 검증했다.

## 3. 수급·포지션 — 이번 점검의 가장 중요한 발견

**무계좌 자동화 경로가 사실상 소멸했다.** KRX Open API 전 카테고리에 투자자별·공매도·프로그램매매가 없고(전수 확인), data.krx.co.kr 는 로그인 필수(실측 `LOGOUT` 반환), 2026-06-01 KRX 공지가 *"pykrx 등 비공식 사설 라이브러리 이용 금지"*를 명문화했다. 공공데이터포털에도 관련 API 0건.
> *2026-09-27 재조사*: 위 KRX 공지는 다시 찾지 못했다. 대신 [KRX 이용약관](https://data.krx.co.kr/contents/MDC/INFO/informationController/MDCINFO003.cmd) 제10조②가 "자동화 수단을 이용한 무단 수집"을 금지한다(시행 2026-08-29) — 결론은 같다.

**무계좌로 되는 예외 둘:**
- **대차잔고(종목별)**: 한국예탁결제원 증권대차 API — https://www.data.go.kr/data/15157426/openapi.do (무료, 자동승인, 일 100회, "출처표시·상업적 이용금지" = 개인용 적합)
- **신용융자(시장 전체)**: ECOS `901Y056` 증시주변자금동향 (월별, 기존 키로 즉시). 일별은 금투협 freesis 비공식 JSON(그레이존, 저빈도 폴링이면 현실적 리스크 낮음)
- 보조: 외국인 소진율은 네이버 일봉에 포함 (opt-in 소스)

**증권사 계좌로 연다 — 멀티 증권사, 토스부터 (2026-09-27, PLAN.md M4):** [토스 Open API](https://openapi.tossinvest.com/openapi-docs/overview.md) REST가 투자자별 매매동향(`investor-trading`) · 프로그램매매(`program-trades`) · 공매도(`short-selling`) · 신용 · 대차를 준다(일별 확정치). WebSocket으로 실시간 시세(KRX+NXT, 미국). **장중 투자자별 수치는 어느 증권사든 가집계(추정)뿐**이다. 허용 IP 등록 필수.

**KIS · 키움도 같은 인터페이스로 추가 등록 — 장중 가집계·실시간 프로그램매매는 이쪽이 강하다:**
- 투자자별 매매동향: `FHPTJ04030000`(시장별) `FHPTJ04160001`(종목별) `FHPTJ04400000`(기관·외인 가집계)
- 공매도 거래량: `FHPST04830000`(일별추이) `FHPST04820000`(상위)
- 신용 종목별: `FHPST04760000` / 프로그램매매: `FHPPG` 계열 + 실시간 WS `H0UNPGM0`
- 키움 REST가 동등 커버(백업): ka10008~ka10066, ka90005~13
- ⚠️ 공매도 **잔고**(잔고공시)는 계좌로도 API 없음 — KRX 화면 수동뿐

> **시사점: 증권사 계좌의 의미가 바뀌었다.** 이전에는 "실시간 시세용 선택 사항"이었지만, 이제 **"수급 범주 전체의 유일한 정식 자동화 경로"**다. 한국 주식에서 수급을 진지하게 본다면 계좌 연결은 사실상 권장 사항이 된다. v1은 무계좌(대차+ECOS+소진율)로 시작 가능. → *2026-09-27: 실시간을 핵심 요구로 격상하면서 멀티 증권사(토스부터)로 확정, Phase 3 → M4로 당김.*

## 4. 기대치(컨센서스) — 제품 루프에 직결

주가는 실적 절대값이 아니라 **기대 대비**로 움직인다. "기대 vs 실제" 대조가 우리 Decision 루프의 본질이므로 이 범주가 특히 중요하다.

**미국 — 완전 자동화 (전부 무료 확인):**
- Alpha Vantage `EARNINGS_ESTIMATES`: EPS 추정 평균·고저·애널 수 + **7일/30일 전 리비전** (기대치 변화 추적 가능). 무료 키, 일 25회 한도(관심종목 소수면 충분)
- Finnhub 무료: 투자의견 분포(`/stock/recommendation`) · 어닝 서프라이즈(`/stock/earnings`) · 어닝캘린더(컨센서스 EPS 포함)
- Nasdaq 비공식 API(`api.nasdaq.com/api/calendar/earnings`) 백업

**한국 — 자체 집계 전략 (단일 API 없음):**
1. 리포트 스트림: `finance.naver.com/research/` — **robots.txt가 명시적 Allow** (조사한 모든 소스 중 유일하게 깨끗한 크롤링 신호) + 한경컨센서스 목록(목표가 숫자 포함). 리포트별 목표가를 수집해 **앱이 자체 평균 계산**
2. 스냅샷: `navercomp.wisereport.co.kr` (robots 없음) 저빈도 수집
3. **수동 입력 폴백 UI 필수** — 전부 비공식이라 파서 파손을 전제

> **설계 원칙 (신규): Decision 기록 시점에 당시 컨센서스 값을 스냅샷으로 함께 저장한다.** 비공식 소스는 사후 유실될 수 있고, "당시 시장 기대가 얼마였나"가 없으면 나중에 결과 대조가 불가능하다.

## 5. 일정(캘린더)

- **FOMC·미 경제지표: Fed 공식 기계가독 JSON** — `federalreserve.gov/json/calendar.json` (FOMC·통계릴리스·베이지북 전부)
- 금통위: 한은 페이지 HTML — 2026년 8회 일자 전부 게시 확인, 연 1회 파싱이면 충분
- 미국 실적 캘린더: Finnhub + Alpha Vantage CSV + Nasdaq API 3중화
- 한국 실적: 단일 공식 캘린더 없음 → **3층 구조**: ① 대형주는 KIND IR일정·DART "IR 개최" 공시로 사전 인지 ② 법정 마감일(분기말+45일)로 추정 ③ DART "영업(잠정)실적" 공시 실시간 감지(사후 확정)
- 배당·권리 일정: 공공데이터포털 주식권리일정 (기존)

## 6. 거시 — FRED 추가로 완성

FRED API(무료 키, 시리즈 전부 실측 확인): 기준금리 `DFF` · 국채 `DGS2`/`DGS10` · CPI `CPIAUCSL` · 고용 `UNRATE`/`PAYEMS` · VIX `VIXCLS` · 유가 `DCOILWTICO`/`DCOILBRENTEU` · 달러 `DTWEXBGS`. yahoo 보완: `DX-Y.NYB`(DXY), `^TNX`. EIA API는 FRED가 유가를 재배포하므로 생략 가능.

## 7. 산업 시황 — 확보 / 격하 구분

**확보 (자동화):**
- 원자재: yahoo 선물 — 금 `GC=F` 은 `SI=F` 구리 `HG=F` 알루미늄 `ALI=F` **철광석 `TIO=F`**(존재 확인) 유가 `CL=F`/`BZ=F` 가스 `NG=F` 농산물 `ZC/ZS/ZW/SB/KC/CT=F`
- 반도체: SOX `^SOX` + **관세청 수출입 API**(공공데이터포털, HS 8542, 월별 확정치)
- 지수·환율: 미 선물 `ES=F`/`NQ=F`, 주요국 지수, 원달러 24시간 `KRW=X`

**스크레이핑 의존 (등급 중):** BDI·SCFI — 관세물류협회 무료 페이지(kcla.kr) / 나프타 — 페트로넷 / 10·20일 잠정 수출입 — 보도자료

**뉴스 헤드라인 격하 (유료 원천):** DRAM/NAND 고정거래가(TrendForce — 월초 보도자료 헤드라인으로) · 철강 제품가 · 석화 스프레드 · Newcastle 석탄 일별. LME 공식가는 COMEX 선물로 실질 대체 완료.

## 8. 뉴스·텍스트

- 헤드라인: 네이버 뉴스 API (기존) — 위키 이벤트의 주 소스. 하루 25,000회, `display`≤100, `sort=date`
- 준실시간 *(2026-09-27, M3 → 2026-09-30 구현)*: 언론사 RSS 폴링 3분 — 연합 `/rss/economy.xml`·`/rss/market.xml`(각 120건) · 한경 `/feed/finance` · 매경 `/rss/50200011/`(각 50건). 비상업·개인 이용만 허용이고 연합은 "AI 학습 및 활용 금지"를 명시 → **제목만 규칙 매칭·알림에 쓰고 모델에 넘기지 않는다**. (LS OpenAPI `NWS` WebSocket은 1~3초 푸시지만 LS 계좌 필요 — 보류)
- 미국 어닝콜: **Motley Fool 트랜스크립트** — robots 허용 확인, 저빈도 수집 가능
- 한국 어닝콜·IR자료: 표준 소스 없음(대형주만 자사 IR 게시, 형식 제각각) → **링크 보관 + 수동 첨부**
- 리포트 PDF 원문: 링크 참조만 (재배포 금지)

## 9~10. 의식적 제외

- **센티먼트·커뮤니티**(종토방·X·텔레그램): 노이즈 대비 신호가 낮고 팩트·출처 기반 철학과 충돌. 제외를 명시적 결정으로 기록. 필요 시 뉴스 헤드라인의 톤이 간접 프록시.
- **대체데이터**(카드매출·위성·앱사용량): 개인 무료 경로 없음. 제외 확정.
